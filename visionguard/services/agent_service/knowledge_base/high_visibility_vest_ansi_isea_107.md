# High-visibility vest required
OSHA general industry rules do not name a vest directly; a high-visibility vest is required where the PPE hazard assessment finds a struck-by risk from moving vehicles, such as forklifts, trucks, cranes or loading docks, 1910.132(d). For work near public roads, construction rules point to the MUTCD, which calls for high-visibility apparel, 1926.201. A worker missing a vest in a forklift or vehicle zone is a struck-by risk.

# Vest standard ANSI/ISEA 107, types and classes
ANSI/ISEA 107-2020 groups garments by type: Type O (off-road, not exposed to public traffic), Type R (roadway and temporary traffic control) and Type P (public safety). Performance Class 1, 2 and 3 add more fluorescent background and retroreflective material for faster traffic and lower light. Type O is Class 1; Type R and P are Class 2 or 3. Replace vests that are faded, dirty or torn, because they lose visibility.
